# Conversor de Monedas 💰

Este proyecto es un **Conversor de Monedas** que permite a los usuarios convertir entre diferentes divisas utilizando tasas de cambio actualizadas a través de una API. La aplicación tiene un menú interactivo que facilita la selección de las conversiones deseadas. 🌍

## Características ✨

- Conversión entre las siguientes monedas:
    - Dólar a Peso Argentino 🇦🇷
    - Peso Argentino a Dólar 🇺🇸
    - Dólar a Real Brasileño 🇧🇷
    - Real Brasileño a Dólar 🇺🇸
    - Dólar a Peso Colombiano 🇨🇴
    - Peso Colombiano a Dólar 🇺🇸
- Validación de entradas para asegurar que solo se ingresen números. ✅
- Llamadas a la API para obtener tasas de cambio actualizadas. 📈
